# Halamesk digital experience

A cinematic, responsive brand site for Halamesk, built from the supplied company profile and visual identity.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Experience highlights

- GSAP and Lenis motion system
- 72-frame, scroll-directed cinematic sequence
- Expanding and parallax imagery
- Pinned horizontal project gallery
- Responsive mobile navigation and layouts
- Reduced-motion support

All project imagery, company copy, brand colors, and contact details are derived from the client-provided documents.
